# Hi, I'm Filip Strózik 👋

The portfolio is a plain HTML, CSS, and JavaScript site published through GitHub Pages. The printable CV source is maintained in [`resume/resume.tex`](resume/resume.tex), and the PDF is compiled and deployed automatically by GitHub Actions at [`Filip Strózik resume.pdf`](resume/Filip%20Str%C3%B3zik%20resume.pdf).

To update the CV, edit the LaTeX source and run `./resume/build-resume.sh` locally. This generates `resume/Filip Strózik resume.pdf`. The workflow requires GitHub Pages to use GitHub Actions as its deployment source.
